# 🌅 DailyRise

Your personal daily growth companion — track prayers, tasks, reading, exercise, expenses, health, and more.

## ⚡ Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Run development server
npm run dev

# 3. Build for production
npm run build
```

## 📁 Project Structure

```
dailyrise/
├── public/
│   ├── index.html
│   ├── manifest.json     # PWA manifest
│   ├── sw.js             # Service Worker
│   └── icon.svg
├── src/
│   ├── main.jsx          # Entry point
│   └── App.jsx           # Main app (all components)
├── package.json
├── vite.config.js
└── README.md
```

## 🚀 Deploy to Vercel / Netlify

```bash
npm run build
# Upload the /dist folder
```

## 📱 Install as App (PWA)
- Chrome → Address bar → Install icon
- Mobile → Share → Add to Home Screen

## 🔧 Tech Stack
- React 18
- Vite 5
- localStorage (offline data)
- PWA (installable)

## ✨ Features
- 🕌 Prayer tracker (Fardh + Nafl + Tasbeeh + Dua)
- 📚 Reading log (Books + Quran + Notes)
- ✅ Daily & Tomorrow tasks
- 💸 Expense tracker with budget
- ❤️ Health (Weight, BMI, Sleep, Water, Mood)
- 🌱 Habit tracker with streak
- 📓 Journal / Diary
- ⏰ Daily Timeline
- 📊 Statistics + AI Weekly Summary
- 🔒 PIN lock security
- 🌙 Dark / Light mode
- 🇧🇩 Bengali / English language
- 📱 PWA — installable as app
